# 내 취업 조건

공고 수집 스킬(`collect-postings`)이 이 파일을 읽고 공고를 찾아 적합도를 매긴다.
자유롭게 고쳐도 된다. 구체적일수록 적합도가 정확해진다.

## 나

- 졸업(예정): 2027년 2월 · 전공: 산업공학
- 찾는 고용 형태: 신입 정규직, 채용연계형 인턴
- 제외: 경력직만 뽑는 공고, 교육생·부트캠프

## 희망 직무와 적합도 기준

- **A (꼭 볼 공고)**: 구매, SCM·물류, 생산관리 — 직무명이 정확히 맞는 공고
- **B (인접 직무)**: 품질, 생산기술, 영업관리
- **C (참고용)**: 대기업·중견기업의 전 직무 공채

## 회사와 지역

- 기업 형태: 대기업, 중견기업, 외국계 (기타기업은 A일 때만)
- 근무지: 서울·경기 우선, 지방은 A일 때만

## 조사할 사이트

- 자소설닷컴, 사람인, 링커리어, 잡코리아
