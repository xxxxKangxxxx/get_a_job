# 디자인 세션 인수인계

먼저 `docs/handoff/README.md`, `docs/PLAN.md`, `docs/handoff/STATUS.md`를 읽는다.

## 앱 한 줄 요약
혼자 쓰는 취업 준비 PWA. 핵심은 **"내 공고 일정 관리 + 오늘 무엇을 어디까지 해야 하는지 알려 주기"**. 이력서·자소서 작성 기능은 없다.

## 사용자 피드백 (가장 중요)
- 1차 시안(https://claude.ai/artifact/1nJ9bFjcMJpooHRq2QjeFK)은 **"너무 별로다. 훨씬 트렌디하고 고급스러워야 한다."**
- 1차 시안은 토스 스타일을 따라 했다: 연회색 배경 #F2F4F6, 흰 둥근 카드, 파랑 #3182F6 하나, Noto Sans KR. 흔하고 밋밋한 결과였다.
- 사용자가 고른 방향 (유지): 홈 = **오늘 할 일 중심**, 분위기 = **친근한 모바일 앱형**, 받은편지함 = **카드 한 장씩 넘기기**.
- 정보 구조는 1차 시안을 참고하되, 시각 언어는 처음부터 다시 잡는다.

## 해야 할 일
1. **레퍼런스 조사**: 2025~2026년 트렌디하고 고급스러운 모바일 생산성/일정 앱을 조사한다 (예: Things 3, Structured, Amie, Sunsama, Linear 모바일, Cron/Notion Calendar, Arc, Raycast, Craft, Apple 기본 앱의 최신 스타일, Dribbble·Mobbin의 한국 핀테크·생산성 앱). 무엇이 "고급스럽게" 보이게 하는지 구체적으로 정리한다(타이포 위계, 여백, 색 절제, 깊이·질감, 모션, 데이터 시각화 방식, 다크 모드).
2. **방향 2~3개 제안**: 각 방향마다 무드 한 줄 + 핵심 규칙 + 홈 화면 시안 1장. 사용자에게 고르게 한다 (AskUserQuestion, 미리보기 활용).
3. **선택한 방향으로 4개 화면 시안**: ① 홈(오늘 할 일) ② 받은편지함 카드 ③ 일정(날짜별 작업 블록 + 시간 부족 경고·해결책) ④ 지원 현황(전형 단계). 기존 아티팩트에 새 페이지/보드로 추가하거나 새 아티팩트로 만든다.
4. **디자인 토큰 문서** `docs/design/tokens.md`: 색(라이트·다크), 글꼴(한글 웹폰트 — Pretendard 셀프호스팅 등 실제 Next.js에서 쓸 수 있는 것), 크기 단계, 간격, 반경, 그림자, 모션. Tailwind v4 `@theme` 변수로 옮기기 쉽게 적는다.
5. **컴포넌트 규칙** `docs/design/components.md`: 카드, 할 일 행, 진행 막대, 경고 배너, 하단 탭, 버튼 종류, 배지(적합도 A/B/C), 빈 상태.

## 화면에 들어가야 하는 정보 (1차 시안 기준)
- 홈: 날짜, 오늘 쓸 수 있는 시간(캘린더 약속 제외), 마감 몰림 경고, 오늘 할 일(공고·시간·진행률 목표 "30%→65%까지"·마감 D-day), 다음 7일 부하, 받은편지함·결정 필요 개수, 공고 추가 버튼.
- 받은편지함: 기업·공고명·적합도·마감·고용형태·근무지·출처, "지원하면 일정은?"(겹침 여부), 관심 없음/보류/지원할래요. 관심 없음 → 이유 고르기(직무·지역·고용형태·기업규모 등).
- 일정: 구글 캘린더 동기화 상태, 시간 부족 경고 + 해결책(포기 후보 / 시간 늘리기) 적용 버튼, 날짜별 작업 블록과 개인 일정.
- 지원 현황: 단계 탭(준비 중·서류·인적성·면접·최종), 카드에 다음 일정·결과 입력 버튼.

## 실제 데이터 예시
LS MnM 신입사원 수시채용(자금) 마감 11/3 · 동국제약 구매팀 마감 10/28 · 기아 생산관리 서류 결과 대기 · SK하이닉스 양산관리 인적성 단계. 적합도 A = 구매/SCM·물류/생산관리/DX 정확 매치.

## 제약
- 구현은 Next.js 16 + Tailwind v4. 아이콘은 lucide-react 사용 예정.
- 터치 영역 44px 이상, 본문 대비 4.5:1, 다크 모드 고려.
- 코드는 고치지 않는다. 결과는 `docs/design/`와 시안 아티팩트로 남기고, STATUS.md 디자인 칸에 링크를 적는다.
